# DeboApp - Overview

## Descripción
DeboApp es una aplicación para gestionar compras en cuotas y deudas entre personas (familiares o amigos), permitiendo visualizar claramente cuánto se debe, a quién y cuándo pagar.

## Problema
Las personas que usan crédito (propio o de terceros) pierden el control al usar herramientas manuales como Excel.

## Objetivo
Centralizar y simplificar:
- Compras en cuotas
- Deudas con terceros
- Pagos realizados
- Cargos adicionales (impuestos, sellos, etc.)

## Público objetivo
- Usuarios personales
- Personas que comparten gastos o usan tarjetas de terceros

## Propuesta de valor
"Sabé cuánto debés, sin vueltas"
