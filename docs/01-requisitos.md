# Requisitos

## Funcionales

### RF01 - Gestión de compras
El usuario puede registrar una compra:
- monto total
- cantidad de cuotas
- interés (opcional)
- persona asociada

### RF02 - Generación de cuotas
El sistema genera automáticamente las cuotas.

### RF03 - Gestión de personas
El usuario puede crear y administrar personas (familiares/amigos).

### RF04 - Registro de pagos
El usuario puede registrar pagos hacia una persona.

### RF05 - Cálculo de deuda
El sistema calcula:
- deuda total
- deuda por persona

### RF06 - Cargos adicionales
El usuario puede registrar impuestos o cargos extra asociados a una compra o persona.

---

## No funcionales

- Usabilidad simple
- Persistencia de datos
- Escalabilidad básica
- Soporte multiplataforma (web + mobile)
